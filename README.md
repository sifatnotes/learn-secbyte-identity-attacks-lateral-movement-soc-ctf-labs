## Learning Path

1. **Understand identity security:** Begin with ticket-related labs and pass-the-hash concepts.
2. **Explore system compromise indicators:** Study lateral movement and privilege escalation investigation.
3. **Investigate suspicious authentication:** Practice analyzing unusual VPN logins and impossible-travel alerts.
4. **Recognize credential attacks:** Compare credential stuffing, password spraying, and brute-force activity.
5. **Build defensive investigation skills:** Finish with SOC triage and EDR case analysis.

Adapt this path to the prerequisites and learning objectives listed by the lab provider.

## How to Use the Labs

1. Select a lab from the collection and open its official page.
2. Review the learning objectives and authorized-environment requirements.
3. Follow the lab instructions and investigate the available evidence.
4. Record findings, indicators, and relevant defensive controls.
5. Review what the investigation reveals and identify opportunities to improve detection.
